# Kamata

複数の画像を横に並べて見比べるための、Windows 用ビューアーです。

**[→ 最新版をダウンロード](https://github.com/victorycats/app-kamata/releases/latest)**

## 何ができるか

- **複数の画像を横に並べて同時に表示**します。画像ごとに拡大・移動・回転ができ、
  ホイールを回すと同じフォルダの次の画像へ切り替わります
- **画像・動画・PDF・書庫(zip / cbz / rar / cbr / 7z)**をそのまま開けます。
  書庫や PDF は展開せずに、中身を1枚ずつ表示します
- 対応形式: `.jpg` `.jpeg` `.png` `.gif` `.bmp` `.webp` `.tiff` `.tif`
  (GIF・WebP はアニメーション再生に対応)
- **横に並べた画像に、それぞれ動画を重ねて表示**します。1枚の画像を1タイルとして扱い、
  各タイル上に動画ファイルやアニメ画像(アニメGIF、アニメPNG、アニメWebP)を重ね配置できます。
  現在試験運用中につき、配置方法はタイルの上下端いずれか40pxのエリアにドラッグアンドドロップのみ
  となっています。画像が先/動画が先いずれの場合でも配置可能。
- **漫画モード**(見開き2画面)、スライドショー、気に入った画像の**ピン留め**、
  よく使うフォルダへの**クイックアクセス**
- 操作は設定画面でほぼすべて変更できます。現在の割り当てを
  「操作早見表」として1枚の画像に書き出す機能もあります

## 動作環境

- Windows 10 バージョン1809 以降 / Windows 11
- 64bit(x64)

.NET や Windows App SDK を別途インストールする必要はありません。

## インストール

インストーラーはありません。[Releases](https://github.com/victorycats/app-kamata/releases)
から zip をダウンロードし、展開して出てくる `Kamata.exe` を実行してください。
実行ファイル1つだけなので、好きな場所に置いて構いません。

設定・履歴などは `%LOCALAPPDATA%\Kamata\` に保存されます。

## デフォルトではないがおすすめの設定

おすすめの設定項目は以下です。どれも個人的にはオンにしておきたいのですが、やりすぎだったり、必要以上に  
時間がかかったりする部分なので、いわゆる玄人志向的な項目となります。<kbd>ピンとクイックアクセス</kbd>のタブに関しては  
さらに込み入っているためここでは触れません。  

<kbd>基本</kbd> ＞ <kbd>全般</kbd> ＞ <kbd>削除の確認ダイアログを表示しない</kbd>  
  画像タイルの下方にカーソルを持っていくとスクラバーパネルが表示されます。パネル内右上にゴミ箱ボタンがあり、  
  表示されている画像をそのボタンでゴミ箱に送ることができます。この項目をオンにすると、削除の際に確認が出ません。  

<kbd>基本</kbd> ＞ <kbd>ウインドウ</kbd> ＞ <kbd>サイズが変わるときに固定する角</kbd>  
  ディスプレイ解像度に対して小さめの、かつ大きさがバラバラの  画像を1枚だけ開いてホイールでめくっていくような  
  使い方の場合、ウインドウサイズが毎回変わってしまい落ち着きません。固定する角を指定して、ウインドウをその角に  
  持っていくと見やすくなります。  

<kbd>基本</kbd> ＞ <kbd>ウインドウ</kbd> ＞ <kbd>最後の1枚を閉じたらアプリを終了する</kbd> or <kbd>すべての画像を閉じたらウインドウモードに戻す</kbd>  
  個人の使い方による部分が大きい設定ですが、読んで字のごとく、アプリが必要なくなったときにどういった挙動を  
  するかという設定です。なおデフォルトでESCがアプリの終了に設定されています。  

<kbd>基本</kbd> ＞ <kbd>ウインドウ</kbd> ＞ <kbd>複数表示中のダブルクリック</kbd>  
  選んだ画像を見やすく表示にすると、例えば3枚表示していてそのうちの1枚の全体を見たいといった場合に、  
  画像をダブルクリックすると他のタイルを追いやって表示します。再度ダブルクリックすると戻ります。  

<kbd>基本</kbd> ＞ <kbd>ウインドウ</kbd> ＞ <kbd>フィットしている軸をスナップしながらパンする</kbd>  
  よくある辺の吸着機能です。画像が見切れている方向には吸着しません。その下の数値を上げると吸着感が増します。  

<kbd>基本</kbd> ＞ <kbd>ホームとスライドショー</kbd> ＞ <kbd>ホームフォルダのスキャン(完全ランダム)</kbd>  
  前提として、「画像を特定のフォルダ以下にまとめて保存している人」向けの項目となります。まず<kbd>ホームとスライドショー</kbd>の  
  一番上の<kbd>ホームフォルダ</kbd>で、画像を保存しているフォルダを指定します。指定が終わったら「スキャンする」ボタンを押し、  
  スキャンが完了するのを待ちます。フォルダの数・画像の数でかかる時間が大きく変わりますが、  
  ルータにぶら下がった簡易NASに保存された500フォルダ・25万ファイルでも10分かからない程度です。  
  <kbd>完全ランダムを使う</kbd>をオンにして設定画面を抜け、ウインドウ右上の▶を押すとスライドショーのランダム再生が始まります。  

<kbd>操作</kbd> ＞ <kbd>画像の送り</kbd> ＞ <kbd>フォルダの端(最初/最後)に達したら</kbd>  
  画像を特定のフォルダ以下に整理している方向けの選択肢です。ファイル名順で  
  次/前のフォルダを開く(見つからなくてもダイアログを出さない)を選択すると、フォルダを意識することなく  
  次のフォルダに進んでくれます。  

<kbd>操作</kbd> ＞ <kbd>画像の送り</kbd> ＞ <kbd>同じ画像を2枚以上表示しない</kbd>  
  複数タイル表示をしている際、「能動的に開く以外で」同じ画像を開かないようにします。例えば複数タイルの  
  めくり操作などを多用する方に向いています。  

<kbd>操作</kbd> ＞ <kbd>画像の送り</kbd> ＞ <kbd>フォルダ移動時に通知する</kbd>  
  上記の<kbd>フォルダの端(最初/最後)に達したら</kbd>で<kbd>次のフォルダを開く</kbd>にしている場合にオンにすると、  
  めくり操作中にフォルダ移動をした場合に、タイル下部に小さめに通知が出ます。  

<kbd>操作</kbd> ＞ <kbd>マウス</kbd> ＞ <kbd>画面端ホバーで横スクロールする</kbd>  
  オンにすると、例えばタイルを3枚表示する設定にしている状態で4枚目のタイルを画面外で開いている場合に、  
  その方向の端にマウスカーソルを持っていくと自動でスクロールする機能です。デフォルトでは  
  右クリックを押したままマウスを動かす必要があるので、若干の省力化になります。  

<kbd>見た目</kbd> ＞ <kbd>表示</kbd> ＞ <kbd>ツールチップを表示する</kbd>  
  アプリの操作に慣れてきたらオフにするのをおすすめします。  

<kbd>見た目</kbd> ＞ <kbd>動画</kbd> ＞ <kbd>動画の自動再生</kbd>  
  オンにすると動画を開いたらすぐ再生を始めます。一般的な動画プレーヤーの感覚で使えます。  

設定・履歴などは `%LOCALAPPDATA%\Kamata\` に保存されます。  

## 不具合の報告

[Issues](https://github.com/victorycats/app-kamata/issues) へお願いします。

アプリの設定画面「このアプリについて」タブにある **「不具合を報告する」** ボタンを押すと、
環境と設定をまとめた報告用の文章がクリップボードに入り、このページが開きます。
そのまま貼り付けて、「何が起きたか」「どうなると思っていたか」「どう操作したか」を
書き足してください。

GitHub アカウントをお持ちでない場合は、https://victorycats.github.io の
連絡フォームからでも構いません。
